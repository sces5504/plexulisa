# 年輪（yearwheel）

一棵上了發條的世界樹，把一整年釘在樹上：樹冠是夏天，樹腳是草地，草地底下樹根倒掛成冬夜；
秋、春、鐘匠工坊和碼頭浮在枝頭，各朝不同方向傾斜，中間還有六顆小島。轉動這顆球，就是轉動一年。

製作順序是先景後軌：`tree.js`（主樹與地形）→ `track.js`（在景裡找路）→ `scene.js`（繞著兩者擺設）。

| 檔案 | 內容 |
| --- | --- |
| `shapes.js` | 只有這顆球用的造型：枝幹（`limb`）、地塊（`land`）、葉團／雪團（`clump`）、冰柱（`spike`）。全部是程式生成的幾何，看得到的就碰得到。 |
| `tree.js` | 中軸的年輪樹、樹冠的枝與葉、托住四季的大枝、十一塊地（草地、冬、秋、春、工坊、碼頭、六顆小島）。葉子最後才長，會避開軌道與站台。 |
| `track.js` | 22 個站台、37 條路線。`link()` 把兩個站台用平滑曲線接起來，兩端用零件組的 `pitch` 捲進各自的平面。 |
| `scene.js` | 每個世界的共用道具與機關擺設。被軌道佔走的位置，道具會自動移到同一塊地上最近的空位。 |

## 關卡

| 關卡 | 路線 | 皮膚／零件／機關 |
| --- | --- | --- |
| 年輪梯 | 樹腳 → 樹洞 → 東枝台 → 樹冠北台 | 藤蔓、木；彈簧門（樹皮門） |
| 樹冠環 | 北台 ↔ 南台，南台 → 夏至台 | 音樂盒、木琴鍵、吊橋 |
| 候鳥線 | 夏至台 → 碼頭 → 秋收場 | 螺旋滑道、吊橋（下垂的谷） |
| 秋收路 | 秋收場 ↔ 果園口、池塘、風車 | 石板路；十字旋轉門 |
| 稜線 | 樹冠北台 → 鐘匠坊 | 黃銅、鐵絲籠；一排鐘擺 |
| 初雪 | 鐘匠坊 → 初雪 → 小溪口；東枝台 → 初雪 | 冰面、雙軌、V 槽、藤蔓 |
| 花園 | 花園門 ↔ 小溪口、點燈人、蘑菇圈 | 象牙、絨布、木琴鍵 |
| 繞日梯 | 樹冠南台繞著太陽兩圈下到日台，再到花園門 | 水晶 |
| 翻面 | 樹腳翻過草地邊緣到倒影，冬市、冰架、水車屋 | 180° 翻面；倒掛與側牆 |

## 資產

| 資產 | 來源 | 點數 |
| --- | --- | --- |
| `blossom_tree`（櫻花老樹） | Meshy text-to-3d＋貼圖，`tools/blender_asset_cli.py` 無頭減面到 16,000 面 | 30 |
| `maple_tree`（秋色版） | 同一個模型，貼圖色相由粉紅轉成琥珀，沒有另外生成 | 0 |
| `harvest_mill`（秋收水車磨坊） | Meshy text-to-3d＋貼圖，減面到 16,000 面 | 30 |
| `frost_belfry`（冰封鐘樓） | Meshy text-to-3d＋貼圖，減面到 12,000 面 | 30 |
| 其餘道具與機關 | 共用庫（原有道具與 `atelier` 素材包），只換配色、縮放、倒掛 | — |

四個模型登記在共用素材目錄（`src/library/assets.js`），別的球也能用。原始檔、提示語與任務 ID 在 `assets/source/<id>/`。
另外在 `src/render.js` 的材質表末尾加了一個 `leafAmber`（秋葉的橘色）。

## 卸下

從 `src/globes/index.js` 移除 `yearwheel` 的匯入和球架項目，再刪除 `src/globes/yearwheel.js` 與本資料夾。
共用層新增的四個素材和一個材質可以留著，不影響其他球。
